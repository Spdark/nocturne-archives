Privacy Policy — Nocturne Archives

Last Updated: November 2026

1. Purpose of This Application

Nocturne Archives Uploader is a private, internal automation tool used exclusively by the owner of the Nocturne Archives YouTube channel (@nocturnearchivestv) to upload videos, manage thumbnails, read channel analytics, and schedule publications via the YouTube Data API v3.

2. Data Collection & Storage

This application does not collect, store, sell, or share personal data from third-party users. OAuth 2.0 credentials and tokens are stored solely on the channel owner's local machine and are used strictly to authenticate with Google's YouTube Data API v3.

3. Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements.
